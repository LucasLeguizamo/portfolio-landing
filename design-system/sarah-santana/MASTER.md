# Sarah Santana — sistema verificado

No usar el `--design-system` genérico de “portfolio”: devuelve Swiss + `#2563EB` y Brutalism. Eso no coincide con la biblia de Sarah.

## Estilos verificados

- Liquid Glass (barra, dock, contacto)
- Soft UI Evolution (carpetas, sombras cálidas)
- Editorial cálido, nunca Swiss azul ni brutalismo

## Color

| Token | Hex | Uso |
| --- | --- | --- |
| Cream | `#FFFBEB` | lavado de página, velo, menú |
| Paper | `#FAF5F2` | agua del escritorio |
| Amber | `#D97706` | acento, selección, halo |
| Yellow | `#F5C400` | mariposa, CTA |
| Pink | `rgba(244, 180, 196, …)` | lavado |
| Teal | `rgba(94, 184, 176, …)` | lavado |
| Ink | `#0F172A` | texto del escritorio |

Nunca `#2563EB` ni paletas gamer saturadas.

## Tipo

- Titulares: Playfair Display
- UI / escritorio: Inter (o SF Pro en el menú macOS)
- No Geist en el escritorio digital

## Escritorio

- Agua iridiscente crema / durazno / aqua
- Barra y dock: vidrio líquido, blur 36–40px
- Cinco carpetas Soft UI, anillo ámbar al seleccionar
- `prefers-reduced-motion`: fade corto, sin coreografía
